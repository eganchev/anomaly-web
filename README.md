# anomaly-web

## app-ads.txt

The `app-ads.txt` file belongs at the root of the website listed as the developer
website for your Android app. Replace the comment in [`app-ads.txt`](app-ads.txt)
with the exact seller records from your ad network before publishing.

With GitHub Pages enabled for this project, the file is available at
`https://eganchev.github.io/anomaly-web/app-ads.txt`. This project URL includes a
path, while ad networks generally look for `app-ads.txt` at the website domain's
root. To make the file available at that root, configure a custom domain for
GitHub Pages or publish it from a user-site repository, and use that domain as
the app's developer website.
